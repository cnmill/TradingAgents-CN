## 💡 数据补全方案

### 方案1: 东财 API 实时获取（推荐）⭐⭐⭐

**优势**：
- ✅ 数据最新（T+0 实时）
- ✅ 包含涨跌家数、成交额等关键指标
- ✅ 无需积分，免费接口

**实施步骤**：
1. 创建 Python 脚本 `scripts/sync_sector_data.py`
2. 每日盘后自动调用（15:30/21:00 两次）
3. 写入 MongoDB 新集合 `sector_daily_quotes`

**API 地址**：
```bash
# 概念板块
curl "http://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=500&po=1&np=1&fltt=2&invt=2&fid=f3&fs=m:90+t:3&fields=f2,f3,f6,f8,f12,f14,f104,f105"

# 行业板块
curl "http://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=100&po=1&np=1&fltt=2&invt=2&fid=f3&fs=m:90+t:2&fields=f2,f3,f6,f8,f12,f14,f104,f105"
```

**字段说明**：
- `f2`: 最新价
- `f3`: 涨跌幅（%）
- `f6`: 成交额（元）
- `f8`: 换手率
- `f12`: 板块代码
- `f14`: 板块名称
- `f104`: 上涨家数
- `f105`: 下跌家数
